## 本轮纠正

- 跨课检索先比较正文匹配，再在同一相关度下分散来源。过去按课程名称拼接，低相关课程可能把真正答案挤出前几条。网页问答、WorkBuddy 检索、教学取材及组卷复用同一个选取实现。保留单课范围和同课别名，返回实际匹配类型与当前来源版本。预算按返回的完整片段计。
- 组卷直接取材，原文不足时返回实际题位。标题命中与单个泛词留给继续查找资料。逐题练习等待作答，题单则一次交付并把解析置后。“接着上次”可直接读取最近三个学习目标。
- `verify_study_quotes` 检查引文、课程、有效版本与停用状态，计算真实页码或时间。它检查的是原文和定位，主张的成立条件仍交由教学与复核流程判断。
- 补充 WorkBuddy 专家团配置。课程导师安排任务，出题员写题，证据复核员检查条件和推导。简单查询与单题在当前对话完成，整套题单和来源冲突才调度成员。源码可生成专家团 ZIP，平台的实际召唤与成员轨迹另做验收。[专家团配置](../workbuddy/expert-team/README.md) · [平台规范](https://open.workbuddy.cn/docs/expert-team)
- 全仓回归复现了 Windows 文本换行导致的 Markmap 校验和变化，以及常驻识别进程退出时日志仍被占用。固定许可证文件换行，识别进程通过输入结束信号正常退出，保留超时处理。具体通过情况见[验证记录](../workbuddy/VALIDATION.md)。

## 下一轮按什么顺序做

| 优先级 | 现在影响学生的地方 | 交付和验收 |
| --- | --- | --- |
| P0 | **打开 WorkBuddy 仍要先找配置。** 安装版、迁移盘符、旧会话工具表都能使源码已更新但客户端连不到。浏览器与 WorkBuddy 也分别提供学习对话 | 在安装流程增加 WorkBuddy 接入与状态检测。主页给“打开 WorkBuddy 继续学习”及可操作的失败原因。用全新 Windows 用户从安装到调用 `study_connection_status` 走一遍，确认 Web 服务停止时仍能查已有索引。网页负责采集、课件导入和回看 |
| P0 | **在客户端走完一轮学习的证据不足。** 检索、讲题、回写、续接分散在工具里。专家团 ZIP、历史对话和协议测试各自只能证明一段 | 用一份原创演示课连续完成“查老师原句 → 只讲解或出一道题 → 给真实测试作答 → 新对话续接 → 今日复习”。另测整套题单时的成员调度。记录实际工具名、版本、是否复用证据、输出及失败恢复，保留默认 WorkBuddy 模型路径 |
| P0 | **课堂定位、知识结论与考核要求有被混用的风险。** 词法命中与逐字引文都可能只支持一个局部条件。现有测试主要用小型夹具，无法估计真实召回和误导率 | 固定匿名或自编评测集，覆盖中英别名、近义冲突、失效版本、错课、同源转写、页码和两种计时基准。记录 Top 3/Top 8 召回、无支持引文率、模型调用数、返回字节和延迟。允许明确返回“资料不足”。将题干条件与参考答案的正确性也纳入评测 |
| P1 | **练完题以后两边的状态容易分开。** 网页练习用 `practice/review`，WorkBuddy 用 `learning_session/learning_step/learning_topic`。今日清单会汇总部分卡点，完整作答和暂停状态仍有多套入口 | 统一课程和主题 ID，并以同一条学习事件贯通出题、原答、用户自评、复习。客户端保留“继续这道题／换主题／暂停”三个操作，验证换对话、刷新来源和重试均保持原进度 |
| P1 | **课堂图和老师口述需要在同一处核对。** 对照页有课件匹配，当前 WorkBuddy 主要取文本、页码和视频链接 | 提供按已索引的课件页、课堂时间请求单页或单帧的能力。先用一个数字电路图和一条带误转写的课堂原句验收。将实际看到的图、推断的关联和考核证据标到正文 |
| P1 | **公开演示链接依赖自己的电脑。** 本机 MCP 有学生数据库和个人设置，评委端需要独立入口和数据 | 先用原创演示资料验证 WorkBuddy 资料库的读取、产物回存与协作。将本机知识索引和公共演示数据分开，发布后用另一账号验证访问范围与实际任务。`127.0.0.1` 只用于本机 |
| P2 | **课程选择与边界处理依赖课程名称。** 同名课程、换学期、选错课和转写未完成时容易用错状态 | 从学校课程 ID、学期与来源版本构造稳定标识，旧名称保留为显示名与查询别名。让“查无资料”“索引待刷新”“还在转写”和“已找到旧版”分别返回可执行的下一步 |

WorkBuddy 承担对话、模型调用、技能与专家调度。SCUT MCP 负责本机索引、版本、回看定位和学习状态。可公开的评审资料和可审阅题单适合进 WorkBuddy 资料库。实时状态继续查 MCP。复习提醒优先复用现有到期规则；如果启用 WorkBuddy 定时任务，只取同一个今日清单，避免两边各记一份期限和反馈。[WorkBuddy 专家](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Expert-Center) · [WorkBuddy 资料库](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Library)

以后面向学生的 Agent 改动以 WorkBuddy 场景验收。PR 写明学生怎么发起、调用了哪些本地工具或平台能力、答案如何回到来源、状态怎样接续。录音和转写可以独立演进，交付时列出 WorkBuddy 能读取的结果及仍须在采集端完成的操作。
