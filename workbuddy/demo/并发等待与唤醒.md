# 并发控制 · 等待与唤醒

本单元的队列、线程和执行轨迹均为原创演示。示例使用 POSIX 条件变量（condition variable），约定线程在同一把互斥锁（mutex）保护下访问队列。

## 第 5 页 · 等待的是一个条件

队列非空是消费者要检查的谓词（predicate）。消费者持有互斥锁检查队列；如果队列为空，调用 `pthread_cond_wait` 时释放锁并进入等待，返回前重新取得同一把锁。锁让检查和取元素都能在受保护的区域内进行。

## 第 6 页 · 两名消费者的执行顺序

甲和乙都在等待。生产者在锁内加入一个元素，并唤醒等待者。乙先拿到锁并取走唯一元素。甲随后拿到锁，此时队列已空。甲重新检查队列后应继续等待。

## 第 7 页 · 两种写法

把 `while` 改成 `if` 后，从等待返回的线程会跳过第二次队列检查。在第 6 页的轨迹中，甲接着取元素时队列已空。用 `while` 时，每次从等待返回都先检查队列。

`if` 写法用于复现问题。

```c
pthread_mutex_lock(&m);
if (queue_empty()) {
    pthread_cond_wait(&cv, &m);
}
pop_front();
pthread_mutex_unlock(&m);
```

`while` 写法在每次返回时重检谓词。

```c
pthread_mutex_lock(&m);
while (queue_empty()) {
    pthread_cond_wait(&cv, &m);
}
pop_front();
pthread_mutex_unlock(&m);
```

## 第 8 页 · 执行顺序练习

如果生产者加入两个元素，乙先拿锁并只取一个，甲拿到锁时看到的队列是什么状态？在其间没有其他线程修改队列的条件下，甲会看到队列仍有一个元素，循环检查通过后可以取走它。
