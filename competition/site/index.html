关于演示

作品名称与赛道

课程补学助手 · 赛道一「AI+教学科研」。公开演示使用原创合成讲义，回放位置为示例。桌面版可在本机连接 SCUT 百步梯和个人资料库。

解决的核心问题

学生缺课或没听懂后，面对回放、字幕、课件与多版转写，很难判断哪一句才是可信依据。本作品把「出处查证 → 带出处的讲解 → 最小练习 → 复习安排」做成一条可操作闭环，让每条结论都能回到原文位置。

知识库来源与核心交互流程

知识库包含原创讲义、模拟字幕和课程通知。考试与作业问答引用所选课程的现行模拟教师通知。讲义先按关键词和术语检索，证据不足时由浏览器计算语义相似度。出处保留页码或小节。

界面来源

线上这一版沿用本机 extension/study.html 学习对话工作台的界面骨架与样式（顶栏、欢迎区、对话气泡、底部输入框、四张场景卡），但把 8 个依赖 chrome.* 与 127.0.0.1:8765 的 JS 模块替换成浏览器端确定性检索。

边界声明

正式软件依托校内课程平台（SCUT 百步梯）的回放、字幕、课件与课程索引，跑在本机 Windows 桌面服务与浏览器扩展里；线上这一版是脱敏交互演示壳，两者是不同执行环境。桌面上的 Skill、MCP 连接器、本地 SQLite 与登录态不会因为发布网页而自动迁移。

公开交付排除私人课件、课堂正文、模型凭据、Cookie 与配对信息。课程解释的教学效果、跨来源纠错的教学价值、知识联系与板书核实仍属部分完成或待验证；页面不把设计目标写成已实现，也不编造学习成效数字。浏览器端的确定性检索是本机规则的等价复刻，不等于 WorkBuddy 原生工作流引擎调度。

本机工作台 → 线上演示版：迁移清单

本机页面原型是 extension/study.html（学习对话工作台，8 个 JS 模块），依赖 chrome.* API、127.0.0.1:8765 本地服务、三个 SQLite、校内 Cookie 与麦克风，因此整页不能直接发布。能搬的是界面骨架、交互、语料与检索规则；需要本机进程或私有数据的功能在线上一律去掉或换实现。
