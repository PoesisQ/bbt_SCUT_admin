# SCUT 课程复习组

整套题单由课程导师在 WorkBuddy 内取材，再交给出题员和证据复核员。遇到课件与课堂表述不一致时，只交由证据复核员核对。单题、找出处和今日清单可以直接在当前 WorkBuddy 对话完成。

使用 WorkBuddy 桌面端连接项目的本地 `scut-study` MCP 0.5.4 或更新版本。在已安装连接器的环境下，角色配置从当前工作空间调用该连接器。个人版创建入口为“专家 → 我的专家 → 专家团 → 创建专家团”。开放平台打包格式见[专家团规范](https://open.workbuddy.cn/docs/expert-team)。

仓库根目录执行 `python scripts/build_workbuddy_team.py` 生成专家团 ZIP，内容包括角色定义、配置和项目头像。它是提交评审前可审阅的专家团配置。本机连接方式由各自的 `prepare_workbuddy.py --install` 生成。

客户端验收用合成课程或可公开的材料。先在 WorkBuddy 召唤专家团，要求出两题且末尾给解析。检查任务中确有主理人取材、出题成员回传、复核成员回传、引文工具核对这四项。再给一个有明确冲突的课堂说法，看是否只召唤复核员并保留未知条件。以客户端工具轨迹和成员产出作为运行证据。
