# 学习页前端改进记录

日期：2026-11-06。对象是当前源码中的 `extension/study.html`，采用原生 HTML/CSS/JavaScript；应用用户指定的 `redesign-existing-projects` 与 `design-taste-frontend`。优先遵循 UX-05 的克制动画和柔和彩色图标要求。

## 需求与改动

| 需求 | 观察到的问题 | 本次改动 |
| --- | --- | --- |
| UX-04、UX-05 | 四个首页快捷入口采用三列布局；首页也启用底部 sticky 输入区，小笔记本和手机上会遮住入口 | 首页依次展示简短引导、输入区和两列快捷入口；手机单列。仅已有对话时启用底部输入区 |
| UX-01、UX-05 | 导航同时呈现六种操作，小屏隐藏课堂记录、学校连接入口 | 主导航保留学习对话、课堂记录、今日清单；资料、同步、学校连接和运行详情集中在按需打开的菜单，窄屏导航独占一行 |
| UX-05、EDU-08 | 字体、边框和次要文字层级松散，四个数字卡片不利于扫描 | 中文系统无衬线字体、统一灰绿底色、主操作绿色、原有颜料品牌图；快捷入口采用细线和彩色小图标；加载骨架仅在处理期间出现，支持减少动画偏好 |
| UX-04、AG-05 | “今日清单”直接发送固定的“今晚只有30分钟” | 先选 15 / 30 / 60 分钟或自定义 1–240 分钟，明确提交后才请求；本标签页恢复上次提交时长，取消和快捷操作保留草稿与附件 |
| UX-03 | 连接标签缺少可辨认的加载、连接成功与失败样式 | 仅由 overview 的实际结果设置连接状态标记；离线时保留具体错误。模型配置状态仍单独显示 |
| DEL-02、DEL-03 | 新样式也需由本地服务交付；源码变更须有范围明确的验证记录 | 新样式进入静态资源白名单并验证 MIME；视觉和交互验证仅使用匿名夹具，证据放在本机忽略目录 |

新布局样式集中在 `extension/study-workspace.css`，仅学习页加载。原有首次启动页、课堂采集、课程笔记和 Android 界面未做视觉重构。现有对话、引文、执行记录、文件导入与课程数据模型继续沿用。

## 浏览器验证

使用独立的 Microsoft Edge 无头实例，运行真实页面与脚本，以匿名 API 夹具替代学校、模型及私人资料；不使用用户浏览器配置或登录 Cookie。证据目录：`.test-tmp/frontend-review/`（被 Git 忽略）。

- 七种视口：320×740、375×812、390×844、768×1024、1024×768、1280×720、1440×1000。均无横向溢出，输入区完整进入首屏；四个快捷入口滚动后均可实际命中，未被输入区遮挡。
- 桌面与手机分别验证时长弹窗、Escape 返回焦点、无效自定义时长切回预设后可提交、草稿/附件/课程不被快捷操作消费、回复后隐藏首页并启用 sticky 输入区。
- 从工具菜单进入资料管理、文件夹导入、运行详情、学校连接时仅有一个活动弹窗。
- Tab 可到跳转链接，Enter 聚焦输入区；减少动画偏好关闭加载骨架动画；离线状态与错误文字可见。
- 浏览器交互报告记录 20 项检查，未捕获 JavaScript 异常或未预期请求。
- 已人工查看桌面与手机首页、手机时长弹窗、桌面工具菜单、手机对话截图。截图中的课程、文件及回复均为界面测试夹具，不是模型回答或真实课程演示。

重现脚本保存在本机 `.test-tmp/review_frontend.py` 和 `.test-tmp/check_frontend_interactions.py`；图片与 `interaction-report.json` 位于上述证据目录。
